## v1.4.7

### 新增功能

- 项目管理新建项目弹窗新增“关联信息”页签，支持创建项目后同步新增流量账号、广告账号、用户 App 关联；关联字段不进入项目创建接口，关联创建失败时仅提示并保留已创建项目（src/pages/project-table/components/ProjectTableForm.tsx）。

### 优化功能

- 优化项目详情关联编辑展示，流量账号和广告账号编辑弹窗不再仅展示 ID，改为展示账号名称、平台和 App 名称等可读信息，查不到名称时再回退到 ID（src/pages/project/components/ResourceTabs/TrafficAccounts.tsx，src/pages/project/components/ResourceTabs/AdAccounts.tsx）。
- 项目详情广告账号关联列表的 App 列优先使用后端新增 `appName` 字段展示应用名称，并在缺失时回退到原有 App ID 展示逻辑（src/pages/project/components/ResourceTabs/AdAccounts.tsx，src/services/project/types.ts）。
- 项目管理新建项目的关联信息中，用户 App 的 App ID 改为必填，流量账号和广告账号仍保持可选（src/pages/project-table/components/ProjectTableForm.tsx）。
- 项目报表投放支出列新增平台组成占比条，按 facebook 蓝色、mintegral 橙色、google_ads 青色展示 `adSpendPlatformComposition` 占比（src/pages/report/project/reportShared.tsx）。
- Dashboard 首页移除未处理工单卡片，顶部概览不再展示待处理工单入口（src/pages/dashboard/index.tsx）。

### Bug 修复

- 修复项目管理详情中点击“关联”新增流量账号、广告账号、用户 App 时复用上一次输入的问题，新增入口会清空旧表单并恢复默认启用状态，编辑入口显式回填当前行（src/pages/project/components/ResourceTabs/TrafficAccounts.tsx，src/pages/project/components/ResourceTabs/AdAccounts.tsx，src/pages/project/components/ResourceTabs/UserApps.tsx）。
- 修复 Dashboard 收益查询重复触发：未选择包名时不再因项目列表加载完成重复请求 `/report/project/query`，今日与本月查询条件完全一致时复用同一次请求结果（src/pages/dashboard/index.tsx）。
